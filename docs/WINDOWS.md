# Windows 版安装与使用

Windows 版使用系统 Text Services Framework（TSF），安装后在 Windows 键盘列表中选择 **出海王输入法**。中文拼音和英文直输共用一个输入源。本地翻译由 Hy-MT2 驱动，原文不发送到翻译 API。

## 版本与适用范围

- Windows 预览版：**0.4.0-preview.1**。
- 目标系统：Windows 10 2004 / 20H1（19041）及以上、Windows 11，**x64** 电脑。
- 安装包同时提供 x64 与 x86 输入法组件，可供两种位数的桌面应用加载。设置 App 和后台输入服务为 x64。
- Windows ARM64、AppContainer / UWP、同一账号多桌面会话及各聊天软件的兼容性，需要分别验证；当前不承诺支持。
- 预览包尚未进行 Windows 发布者签名。正式版本应完成签名和 Windows 10/11 实机验收后再发布；不要关闭系统安全保护。

实际已完成的验证范围以本页末尾的验证记录和对应 GitHub Actions 为准。

## 安装

1. 从 [Releases](https://github.com/sapplex-sz/SailKing/releases) 获取 Windows 安装包 `SailKing-0.4.0-preview.1-Windows-x64.exe`。未公开的草稿不会出现在普通访问者的下载列表中。
2. 运行安装包。注册系统输入法需要管理员权限，安装位置默认为“Program Files / SailKing”。不需要另外安装 Python、Ollama 或 .NET。
3. 打开 **出海王输入法**，在“新手设置”中点击 **启用出海王**。
4. 按 **Win + Space** 选择出海王。在试打框输入 `nihao`，按空格选出“你好”。粘贴文字不会完成试打。

如果键盘列表中没有出海王，进入 **设置 → 时间和语言 → 语言和区域 → 中文（简体，中国）→ 语言选项 → 键盘**，添加出海王；尚未添加中文时先添加该语言。安装器使用 TSF 的注册接口，不覆盖默认键盘设置。

App 不另加托盘图标。后台输入服务会随登录启动；退出设置 App 后仍可使用输入法。

## 输入与翻译

| 按键 | 行为 |
|---|---|
| Win + Space | 切换系统输入源 |
| Shift | 在出海王的中文拼音和英文直输之间切换 |
| 空格 / 数字 | 选择当前页候选 |
| Page Up / Page Down | 翻候选页 |
| Ctrl + Shift + T | 开启或关闭翻译输入 |
| Enter（翻译输入中） | 生成译文预览；再次 Enter 确认上屏 |
| Ctrl + Enter（翻译输入中） | 原文上屏 |
| Esc | 取消翻译、返回草稿或取消当前组合输入 |
| Ctrl + Enter（工作台中） | 手动翻译 |

译文上屏通过 TSF 完成，不会自动发送消息。切换输入框会取消原输入框的任务，避免提交到其他位置。密码、PIN、私密输入范围和禁用输入法的输入框会绕过本项目的拼音与翻译处理。

候选窗采用紧凑布局。拖动标题固定位置，之后继续在该位置显示；右键选择“跟随光标”，或在 App 设置中恢复跟随。多屏位置会限制在可用屏幕范围内。

## 准备本地模型

在 **设置 → 本地翻译模型** 点击下载。Windows 预览版采用 **Hy-MT2 1.8B Q4_K_M**，约 **1.13 GB**，建议至少 **8 GB 内存**。普通拼音和英文无需下载模型。

下载使用固定模型版本，检查文件大小与 SHA-256 后原子安装。后台服务在首次加载时再次校验。下载失败不会覆盖已安装的模型；取消只移除本次下载的临时文件。

Windows 没有 Apple Translation 引擎，当前也不使用 Mac 的 ARM NEON 1.25-bit 运行时。模型许可为 Apache-2.0，安装包包含相关说明。

后台服务会选择适合当前 CPU 的 AVX2 运行组件，并保留基础 x64 组件用于回退。目前仍需改善 CPU 翻译速度，测试设备上的短句首次翻译约需 80 秒；拼音与英文输入不加载翻译模型。

## 更新与卸载

更新前切换到其他系统键盘并关闭出海王 App，然后运行新安装包。安装器会关闭当前用户的本项目输入服务，更新后重新打开 App；正在使用旧输入法组件的其他应用可能需要退出或重新登录后才加载新组件。

卸载入口为 **Windows 设置 → 应用 → 已安装的应用 → 出海王输入法 → 卸载**。也可点击出海王设置中的“卸载”打开该页面。卸载器移除两种位数的 TSF 注册、App 与启动入口，**保留本地模型、词库和个人偏好**。如系统提示需要重新登录或重启，请先保存其他应用的工作。

个人数据位于 `%LOCALAPPDATA%\SailKing`，偏好位于当前用户的 `Software\SailKing` 注册表项。需要彻底清除个人数据时，请在卸载并退出相关应用后自行删除这两处；这些内容可能含已学习的词语，删除后无法恢复。

## 从源码构建

在 Windows 上准备 Visual Studio C++ 桌面构建工具、Windows SDK、CMake、.NET 10 SDK、7-Zip 和 Inno Setup 6。运行：

```powershell
powershell -ExecutionPolicy Bypass -File windows/scripts/build.ps1
```

此参数仅用于运行本次已检查的项目构建脚本，不改变机器的默认执行策略。构建脚本下载带 SHA-256 固定校验的 librime 和 llama.cpp，生成 x86/x64 输入法、本地服务、包含 .NET 的 App 和安装包。

输出位于 `build/windows/`，包括安装程序、SHA-256 清单和可检查的 staging 目录。依赖缓存位于当前用户的 `SailKingBuildCache`，不进入源码仓库。构建与验证流程见 [.github/workflows/windows.yml](../.github/workflows/windows.yml)；依赖审查说明见 [windows/UPSTREAM.md](../windows/UPSTREAM.md)。
