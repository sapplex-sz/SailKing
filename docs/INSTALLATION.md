# 安装与卸载

## 安装

适用设备：Apple Silicon Mac，macOS 26 或更新系统。

1. 从本项目 GitHub Releases 下载经过 Developer ID 签名和 Apple 公证的安装镜像。
2. 打开镜像，将“出海王输入法.app”拖到“应用程序”，退出镜像，再从应用程序打开 App。
3. 在新手设置中点击“安装组件”。安装发生在当前用户目录，无需管理员密码；更新保留旧版本备份、模型、偏好和用户词库。
4. 打开系统键盘设置，在“文本输入 → 编辑 → ＋ → 简体中文”中添加“出海王输入法”。只需添加一个输入源；英文显示为 SailKing。
5. 从屏幕右上角输入法菜单选择出海王，再完成新手设置中的真实拼音试打。

普通拼音和英文输入可直接使用。需要翻译时，再选择 Apple 翻译语言包或下载本地模型。

若输入法没有出现在菜单中，请先确认系统已经添加该输入源，并开启“在菜单栏显示输入法菜单”。保存工作后退出登录再登录可使系统重新读取输入法组件。不要关闭系统安全保护来安装。

## 更新

退出旧 App 后，用新版替换应用程序里的 App，再打开新手设置更新输入法组件。组件安装器会暂时切换到其他输入源、退出旧输入法进程、保存旧版本，再安装新版并恢复原输入源。

输入法内部文件名为 `~/Library/Input Methods/海王输入法键盘.app`，显示名称仍是出海王。请保持此内部文件名以避免系统登记残留。旧版独立“海王·英文”会迁移到统一输入源。

## 卸载

1. 切换到 ABC 或其他输入法，在“系统设置 → 键盘 → 文本输入 → 编辑”中选中出海王，点击“−”并完成。
2. 退出出海王 App，将 `~/Library/Input Methods/海王输入法键盘.app` 移到废纸篓。也可在 App 的“使用指南 → 卸载输入法”中打开组件文件夹。
3. 将应用程序里的“出海王输入法.app”移到废纸篓。如菜单仍有残留，保存工作后退出登录再登录。

仅停用输入法时完成第 1 步即可。上述操作保留模型、词库与偏好，以便重新安装；不自动删除个人词库。
