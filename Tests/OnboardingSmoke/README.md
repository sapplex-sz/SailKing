# 输入法新手设置验证

运行 `bash Tests/OnboardingSmoke/run.sh`。测试在非 iCloud 本机目录构建隔离的原生预览程序，用生产 SwiftUI 引导分别渲染中文和英文的安装、更新、系统添加、真实试打入口及可选翻译配置五种状态，输出十张截图。每张渲染后核对状态未被真实系统查询覆盖，并验证 NSTextView 的标记文字、中文提交和模型写回回调。

预览只使用 DEBUG fixture 和独立临时偏好，不安装组件、不改变当前输入源、不下载模型。它证明布局与回调边界，不能证明系统输入菜单可见或真实 Rime 输入成功。纯状态、版本比较、延期／完成持久化、粘贴／其他输入源排除由 `Tests/HaiwangCoreTests/InputMethodSetupTests.swift` 覆盖。

真实桌面检查另行使用已签名 App：首次更新、保留工作台进程、打开系统键盘设置、菜单确认、`nihao` → 空格 → `你好`、粘贴不解锁、完成状态及重新打开入口。实际记录见 `docs/VALIDATION.md`；用户对右上角系统菜单可见性的确认与 API 状态分别记录。
